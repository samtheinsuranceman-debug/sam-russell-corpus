- Tiers: Common → Legendary (1 in 1,000 to 1 in a billion)
- KEY INSIGHT: They treat traits as INDEPENDENT and multiply probabilities

## Key Observation for AQAL Model
- MBTI uses only 4 binary dimensions (E/I, S/N, T/F, J/P) = 16 possible types
- Rarest type (INFJ) is only 1 in 67
- With 22 dimensions of intelligence, each scored on a continuous scale, combinatorial rarity explodes exponentially
- If each of 22 dimensions has even 5 possible levels, that's 5^22 = 2.38 trillion possible profiles
- The math supports extreme rarity claims when measuring across many dimensions

## HowRareAmI Methodology (Key Formula)
Combined Rarity = Product of individual trait probabilities
Example: If trait A = 10% and trait B = 5% and trait C = 2%
Combined = 0.10 × 0.05 × 0.02 = 0.0001 = 1 in 10,000

This assumes independence. In reality, traits correlate (g-factor in IQ).
Our model needs to account for correlations between intelligence dimensions.
