# CHC Theory: How IQ Tests Decompose Intelligence

## Cattell-Horn-Carroll (CHC) Theory Structure

### Three Strata:
- **Stratum III**: g (general intelligence) — single factor
- **Stratum II**: 16 Broad Abilities
- **Stratum I**: 80+ Narrow Abilities

### The 16 Broad Abilities (Stratum II):
1. **Gf** — Fluid Intelligence (novel reasoning, pattern recognition)
2. **Gc** — Crystallized Intelligence (acquired knowledge, vocabulary)
3. **Gq** — Quantitative Knowledge (mathematical knowledge)
4. **Grw** — Reading & Writing Ability
5. **Gsm** — Short-Term Memory
6. **Glr** — Long-Term Storage & Retrieval
7. **Gv** — Visual Processing (spatial reasoning)
8. **Ga** — Auditory Processing
9. **Gs** — Processing Speed
10. **Gt** — Reaction/Decision Speed
11. **Gps** — Psychomotor Speed
12. **Gk** — Kinesthetic Abilities
13. **Go** — Olfactory Abilities
14. **Gh** — Tactile Abilities
15. **Gp** — Psychomotor Abilities
16. **Gkn** — Domain-Specific Knowledge

## WAIS-IV Structure (What Standard IQ Tests Actually Measure)

### 4 Index Scores from 10 Core Subtests:

**Verbal Comprehension Index (VCI):**
- Similarities (abstract verbal reasoning)
- Vocabulary (word knowledge, verbal concept formation)
- Information (general knowledge)

**Perceptual Reasoning Index (PRI):**
- Block Design (spatial visualization, analysis)
- Matrix Reasoning (fluid reasoning, pattern recognition)
- Visual Puzzles (visual-spatial reasoning)

**Working Memory Index (WMI):**
- Digit Span (auditory short-term memory, attention)
- Arithmetic (quantitative reasoning, concentration)

**Processing Speed Index (PSI):**
- Symbol Search (visual scanning, speed)
- Coding (visual-motor speed, attention)

### What IQ Tests ACTUALLY Measure (Intelligence Lines):
1. Verbal/Linguistic reasoning
2. Fluid/Abstract reasoning
3. Spatial/Visual reasoning
4. Working memory capacity
5. Processing speed
6. Quantitative reasoning
7. General knowledge (crystallized)

### What IQ Tests DO NOT Measure:
- Emotional intelligence
- Interpersonal intelligence
- Intrapersonal/self-awareness
- Kinesthetic/bodily intelligence
- Musical intelligence
- Creative/generative intelligence
- Spiritual intelligence
- Moral/ethical development
- Systems thinking
- Practical/street intelligence
- Narrative/storytelling ability
- Empathic capacity
- Aesthetic intelligence
- Ecological awareness
- Strategic thinking

## KEY INSIGHT: IQ Measures ~7 Lines. We Measure 22.

IQ tests capture approximately 7 of the 22+ possible intelligence lines.
This means IQ is measuring roughly 1/3 of the full picture.

A person with IQ 130 (top 2%) might be:
- Top 2% in cognitive/analytical lines
- Average in emotional/interpersonal lines
- Below average in kinesthetic/somatic lines
- High in spiritual/moral lines

Their PROFILE RARITY across all 22 lines could be anywhere from 1 in 100 to 1 in 1,000,000 depending on the specific combination.
