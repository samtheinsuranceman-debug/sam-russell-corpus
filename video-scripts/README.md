Teleprompter scripts for HeyGen avatar videos. Each file states its runtime and
word count; [bracketed] cues are stage directions — delete them before generating
so the avatar doesn't read them aloud.

| File | Runtime | Use |
|------|---------|-----|
| `FOUNDER_INTRO_3MIN.md` | ~3:00 | Founder/origin story ("Ninety Seconds" / $5M) — cross-venture |
| `AQAL_32_LINES_90SEC.md` | ~1:30 | JoinAQAL 32-lines intelligence explainer |
| `AQAL_32_LINES_60SEC.md` | ~1:00 | Short teaser cut of the 32-lines explainer |

Honesty: scripts use only the project's locked facts (32 lines, 8-AI panel,
voice-first, each line measured ≥4 times, >16 independent of g, controlling
weakness). No fabricated figures. The "100% uncorrelated with g" phrasing is
included per owner direction; a producer note in each 32-lines file records the
more conservative "independent of g" alternative.
