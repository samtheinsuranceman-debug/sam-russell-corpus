## What the avatar may say on this page

- One deterministic engine chains every calculator concept across multi-year windows of five, ten, twenty or thirty years, or any custom length.
- Every window starts from the previous window's ending state: income, expenses, assets, debts, properties and policy values all carry forward automatically.
- Each calculator is a module that can be switched on or off, and the engine reports what each module contributed so the advisor can explain the result.
- Inputs are entered once: practice income, expense changes ahead, long-term debts one per line with balance, rate and payment, properties, and the appreciation per six-to-seven-year recycle cycle if the visitor wants to override the default.
- Spoken notes from the microphone can be pasted straight into the inputs.
- Same inputs always give the same outputs. There is no hidden randomness in this engine.
- Later windows show what the plan does with second and third recycled properties and when policy income begins, under the printed assumptions.
- The engine's own contract says it: every number is a projection under stated assumptions, not a promise.
