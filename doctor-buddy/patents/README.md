## Filing strategy

**Priority 1 — file immediately.** Applications 01, 03, 07, 09 and 13 carry confirmed patent
whitespace and are the most defensible. File as provisionals to secure priority dates.

**Priority 2 — within 6 months.** Applications 02, 04, 06 and 08 have strong novelty but
benefit from reduction to practice (working prototypes) before filing.

**Priority 3 — within 12 months.** Applications 05, 10, 11, 12 and 14 sit in more competitive
space and were differentiated through the enhancement process.

**Continuations.** After initial filings, continuation-in-part applications should expand
claims as the platform evolves.

## Patentability defenses

Every application is drafted against three statutory bars:

- **§ 101 (Alice Corp.)** — each claim ties the abstract idea to a concrete technical
  implementation (e.g. Tucker tensor decomposition on FPGA hardware, not merely
  "simulating life trajectories").
- **§ 102 (novelty)** — each application cites the closest prior art and differentiates
  explicitly.
- **§ 103 (non-obviousness)** — each layers multiple algorithmic components a person skilled
  in the art would not combine absent this teaching.
