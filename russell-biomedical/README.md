# Russell BioMedical — Research & IP Venture Site

Self-contained website (`index.html`, no build, no dependencies) for
RussellBIOmedical.com. Presents Russell BioMedical honestly as a research and
intellectual-property venture that mines open biochemistry literature for
patentable, cross-pollinated intersections — anchored to the BioChem Atlas
library (`../biochem-library/index.html`).

## Sections
Mission · What We Do · Discovery Method (6-step pipeline) · Research Library
(links to BioChem Atlas) · IP Pipeline (honest staging — nothing filed yet) ·
Transparency & Honest Scope · Contact.

## Honesty line held
- NOT a clinical provider; no medical advice, diagnosis, treatment, or
  efficacy/safety/regulatory claims.
- No fabricated findings, citations, or DOIs.
- IP pipeline states plainly that nothing is filed or patent-pending.
- Grades summarize published third-party rankings, labeled as a curated tier.

## Deploy / send
Open `index.html` in any browser. Before publishing, set a real contact address
in the Contact section (kept out of source until then). Deploy on any static
host; keep it in the same parent folder as `biochem-library/` so the "Open the
Research Library" link and the live institution-count reflect resolve.
