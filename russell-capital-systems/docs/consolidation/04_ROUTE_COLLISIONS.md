## Rule

A collision means both repositories answer the same URL. **The base implementation wins by
default.** A donor version may replace it only with a documented comparison and a passing
regression run.

> ### On the "391 pages"
>
> The brief referred to 391 pages. Measured: the base already carries **722 page components and
> 612 routes**. The donor adds **86 routes the base does not have**, and **227 paths
> collide. The migration is therefore much smaller than a 391-page import — most of the surface
> already exists in the base.
