Access Models & Data Standards

Open

Freely downloadable/queryable, often via public APIs. Most repositories here.

Registered / controlled

Human-subject data (dbGaP, UK Biobank, All of Us, ImmPort) requires application, approval, and a data-use agreement. This library links to the front door; it never holds or redistributes controlled data.

Accessions & identifiers

Records are cited by stable IDs — DOI, PMID, PDB ID, NCT number, Entrez Gene ID, UniProt accession — so any result is independently verifiable at its source.

Licensing

Each repository sets its own license/terms. Some (KEGG, DrugBank) are open for academic use but licensed commercially. Check terms before commercial use.

Method & Honesty

Real. Every repository is real with a verified URL. Live results are fetched from the source APIs at query time — accessions and DOIs are theirs. No fabricated datasets, records, or IDs.
What this is. A curated directory + live front-end over public biomedical data infrastructure — the fastest honest way to reach the world's data without warehousing or re-hosting it.
What it is NOT. Not a data owner or re-distributor; not a source of controlled/patient data; not medical advice. Controlled datasets require their own approvals.
Live APIs used. Europe PMC REST · RCSB PDB Search · ClinicalTrials.gov API v2 · MyGene.info — all free, no key.
Ecosystem. Pairs with BioChem Atlas (institutions & findings) and Russell BioMedical (the research & IP venture).
